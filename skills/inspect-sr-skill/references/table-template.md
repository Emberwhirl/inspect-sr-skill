# INSPECT-SR Table Template

Use this markdown structure when the user wants a completed INSPECT-SR table and has not supplied a DOCX template. Put each domain name in a section heading, not in a repeated table column. Keep the standard response options exactly: `Yes`, `No`, `Unclear`, or `Not applicable` for checks; `No concerns`, `Some concerns`, or `Serious concerns` for domain and study judgements.
